Field configurations

Every card is one config permutation. The sticky bar drives all of them live through the handle API — pause, resume, destroy/recreate (leak check), and a global intensity slider (eased, so it fades rather than snaps). Future "skins" (glow, shimmer, pulse, rainbow) are noted in the roadmap; softness below is the first step toward glow.
